<h2 style="text-align: center;">Chip Shape</h2>

| Shape | Effect / Base Value |
| :---: | :---: |
| <img src="/assets/chips/ultrashape.png" width="50"><br>**Ultrashape** | Counts as all shapes |
| <img src="/assets/chips/shapeless.png" width="50"><br>**Shapeless** | Doesn't count as a shape<br>+8 extra base when played<br>+10 extra base when discarded<br>+14 extra base when kept in hand while playing |
| <img src="/assets/chips/boomerang.png" width="50"><br>**Boomerang** | Counts as a triangle/square chip<br>It returns to the hand the first time it's played in a round |
| <img src="/assets/chips/star.png" width="50"><br>**Star** | Counts as a pentagon chip<br>[chance] chance of getting the extra base from the chip on the right<br>This effect can only be activated once per turn |
| <img src="/assets/chips/realhexagon.png" width="50"><br>**Real Hexagon** | Counts as a hexagon chip<br>[chance] chances of scoring x1.2 base<br>The effect can be reactivated |

<h2 style="text-align: center; margin-top: 20px;">Sticker shape</h2>

| Shape | Description |
| :---: | :---: |
| <img src="/assets/chips/knife.png" width="50"><br>**Knife sticker** | [chance] chances to kill the chip next to it and keep its base score (value + extra base)<br>This effect can only be activated once per turn |
| <img src="/assets/chips/duplicator.png" width="50"><br>**Duplicator sticker** | [chance] chances to duplicate this chip<br>This effect can only be activated once per turn |
| <img src="/assets/chips/retrigger.png" width="50"><br>**Square sticker** | Retriggers it 1 time per each epic card |
| <img src="/assets/chips/parallelepiped.png" width="50"><br>**Parallelepiped sticker** | Retriggers it 1 time per each supreme card |
| <img src="/assets/chips/saw.png" width="50"><br>**Saw sticker** | [chance] chance to level up the combos played when scoring (the chances are applied separately to each combo)<br>This effect can only be activated once per turn |
| <img src="/assets/chips/hourglass.png" width="50"><br>**Hourglass sticker** | [chance] chance to level up all combos played this turn and delete this chip<br>This effect can only be activated once per turn |
| <img src="/assets/chips/stagnant.png" width="50"><br>**Stagnant sticker** | x1.25 base when you hold it in your hand |
| <img src="/assets/chips/cross.png" width="50"><br>**Cross sticker** | [chance] chance of getting a consumable by discarding this<br>Else you'll get a sticker |
